# London Housing Data Analysis (Python)

A data analysis project using a London housing dataset to explore property prices, crime rates, and other housing-related statistics across different areas of London.

## Overview

Analyzed housing and crime data to examine geographic differences in property prices and crime rates across London. Used Python and Pandas to explore the dataset, calculate statistics, and identify patterns among different areas.

## Development Context

**Guided Learning Project**

Completed while following instructional material focused on Python data analysis. The project provided hands-on practice using Pandas to explore geographic datasets, calculate statistics, and compare information across different areas.

## Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- Exploratory Data Analysis

## Features

- Analysis of housing prices across London areas
- Exploration of regional crime rates
- Calculation of housing-related statistics
- Geographic comparisons of housing characteristics
- Data filtering, grouping, and aggregation using Pandas

## Files

| File | Description |
|---|---|
| `London Housing Data.csv` | Source dataset containing London housing and related information. |
| `London Housing Dataset.ipynb` | Jupyter Notebook containing the Python code and analysis. |

## Learning Objectives

- Develop practical experience using Python and Pandas.
- Explore and analyze geographic datasets.
- Practice data filtering, grouping, and aggregation.
- Calculate and interpret descriptive statistics.
- Compare regional differences in housing prices and crime rates.

## Analytical Considerations

The project explores geographic patterns in housing prices and crime rates. Differences between areas do not, by themselves, establish a statistical relationship or demonstrate that one factor causes changes in the other.
